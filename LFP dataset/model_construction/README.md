# Model construction

Select a model directory, edit its `config.py`, and run `python main.py` from that directory. Each method has a separate entry and configuration.

| Directory | Methods |
| --- | --- |
| [Proposed framework](Proposed%20framework/README.md) | Gated fusion and FiLM |
| [Baseline group 1](Baseline%20group%201/README.md) | XGB, RF, CGB, LGBM |
| [Baseline group 2](Baseline%20group%202/README.md) | MLP, CNN, LSTM, Transformer |
| [Baseline group 3](Baseline%20group%203/README.md) | DA-AL, DA-MMD, DA-CORAL, SSL-PL |
| [Baseline group 4](Baseline%20group%204/README.md) | MLP, CNN, CGB, LGBM with tail and upstream inputs |

See the [dataset README](../README.md) for data, settings and output details.
