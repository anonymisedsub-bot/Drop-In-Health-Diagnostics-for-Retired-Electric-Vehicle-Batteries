# NMC data terms — academic research use only

The NMC_A and NMC_B raw measurements and processed datasets in this release
are made available for academic research only. Commercial use is not permitted
under these terms.

This applies to the released NMC raw workbooks and processed measurement/data
arrays, including their copies elsewhere in this package. The policy follows
the academic-only, non-commercial data-use statement of the
[original LFP data provider](https://github.com/CETL-HFUT/Imbalanced-retired-battery-data).
It does not assign that provider any ownership of the NMC data or change the
provider's own LFP terms.

These are data-specific use terms, not an MIT licence for the NMC measurements.
The package's MIT software licence continues to apply to the code within its
stated scope. Citation information is in [CITATION.md](../../CITATION.md), and
data availability is described in
[AVAILABILITY.md](../../AVAILABILITY.md).
