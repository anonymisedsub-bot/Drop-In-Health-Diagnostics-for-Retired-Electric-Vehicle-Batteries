# Numerical results

- `reference/`: supplied numerical results underlying manuscript Figure 7.
- `figure_data/`: generated numerical plotting tables or source indexes and dimensions.
- `runs/<mode>/`: newly generated numerical outputs; created on demand.
- `model/`: supplied trained checkpoint and saved split/training state. Model code is in `../model/`.

All panel PNGs and visual QA belong to `../visualization/outputs/`. New-run plots belong to `../visualization/outputs/runs/<mode>/`. Reference data are protected from ordinary run outputs.
