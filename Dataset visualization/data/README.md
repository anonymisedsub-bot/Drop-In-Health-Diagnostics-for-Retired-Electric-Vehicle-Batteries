# Dataset Files

Place the source MATLAB data files used by the notebooks in this directory:

- `CETL_data_processed.mat`
- `CETL-data.mat`

Alternatively, keep the data outside the repository and set the environment
variable `BATTERY_DATA_DIR` to the directory that contains these files.

Large raw data files are intentionally not duplicated in this visualization
folder unless the journal data policy requires bundling them here.
