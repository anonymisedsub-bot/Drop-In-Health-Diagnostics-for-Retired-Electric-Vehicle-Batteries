# Figure 8 visualization outputs

The `outputs/` directory directly contains the panel PNGs, overview, caption and visual verification metadata. Plotting code is in this `visualization/` directory. Numerical plotting sources are in `../results/figure_data/`; the panel manifest links to them.

New runs put their plots in `outputs/runs/<mode>/`, with numerical tables in `../results/runs/<mode>/`. See `../../docs/FIGURE_OUTPUTS.md` for the common layout and commands.
