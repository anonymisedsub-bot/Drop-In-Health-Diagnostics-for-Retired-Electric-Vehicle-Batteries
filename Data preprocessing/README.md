# Data preprocessing for retired lithium-ion battery diagnosis

This folder contains the raw MATLAB data file, the preprocessing script, and the processed data matrix used for downstream retired battery diagnosis and modelling. The structure is intended to support reproducible analysis for a Nature Communications-style submission, including explicit data provenance, preprocessing parameters, software requirements, and file integrity information.

## Folder contents

| File | Size | Role |
| --- | ---: | --- |
| `CETL-data.mat` | 72.17 MB | Raw battery cycling dataset. The MATLAB script loads the variable `unbalanced_data` from this file. |
| `data_processing_code_V1.m` | 0.01 MB | MATLAB preprocessing script for quality control, interpolation, incremental capacity extraction, visualization, and saving processed matrices. |
| `CETL_data_processed.mat` | 9.31 MB | Processed dataset generated by `data_processing_code_V1.m`. |
| `README.md` | - | Documentation for reproducing the preprocessing workflow. |

## Data overview

The raw dataset contains discharge voltage and capacity profiles from retired battery cycling records. In `data_processing_code_V1.m`, the raw variable `unbalanced_data` is assigned to `data` and the following fields are used:

| Raw field | Description | Unit used in raw processing |
| --- | --- | --- |
| `data.Vd` | Discharge voltage sequence for each sample/cycle. | mV before conversion |
| `data.Qd` | Discharge capacity sequence for each sample/cycle. | mAh before conversion |
| `data.Vp` | Voltage profile field used for iterating over available records during quality control. | mV |
| `data.Capacity_labels` | Capacity labels aligned with the raw records. | As stored in source file |

The processed file `CETL_data_processed.mat` stores:

| Processed variable | Description | Shape convention | Unit |
| --- | --- | --- | --- |
| `processed_Vd_mat` | Voltage grid used for interpolated discharge capacity curves. | `N_voltage_grid x N_valid_samples` | V |
| `processed_Qd_mat` | Interpolated discharge capacity curves on the voltage grid. | `N_voltage_grid x N_valid_samples` | Ah |
| `processed_vIC_mat` | Voltage grid corresponding to incremental capacity curves. | `(N_voltage_grid - 1) x N_valid_samples` | V |
| `processed_qIC_mat` | Incremental capacity curves, calculated as `dQ/dV`. | `(N_voltage_grid - 1) x N_valid_samples` | Ah V^-1 |

## Preprocessing workflow

The workflow implemented in `data_processing_code_V1.m` consists of five main stages.

1. Data initialization

   The script loads `unbalanced_data` from `CETL-data.mat`, then extracts voltage profiles, capacity profiles, and capacity labels.

2. Quality control and anomaly filtering

   Records are removed if they meet any of the following criteria:

   - `length(data.Qd{i}) < 1000`
   - minimum discharge voltage in `data.Vd{i}` is greater than `3000 mV`
   - capacity at the 1000th sampled point is greater than `10000 mAh`
   - initial discharge voltage is lower than `3300 mV`

3. Stage-1 coarse interpolation

   Discharge capacity profiles are aligned over a coarse voltage range:

   - voltage range: `3300:-3:3000 mV`
   - smoothing method: moving average with window length `100`
   - interpolation method: linear interpolation with extrapolation
   - sliding window length: `50`

4. Stage-2 high-resolution interpolation

   The filtered voltage and capacity sequences are converted from `mV` to `V` and from `mAh` to `Ah`. Curves are smoothed, truncated, reversed for monotonic consistency, split into weakly monotonic segments, and interpolated onto a fixed voltage grid.

   Main parameters:

   | Parameter | Value | Description |
   | --- | --- | --- |
   | `Vtr` | `2.8 V` | Tail-section threshold; retains the discharge section where `V < Vtr`. |
   | `Vinterval` | `5e-3 V` | Voltage-grid interval. |
   | `Vd_grid` | `2.5:0.005:3.5 V` | Target voltage grid for high-resolution interpolation. |
   | `mono_tol` | `1e-6 V` | Tolerance for splitting weakly monotonic voltage runs. |
   | interpolation | `pchip` | Shape-preserving cubic interpolation within monotonic voltage segments. |
   | fallback | linear extrapolation and nearest-neighbour filling | Used for boundary and internal missing values. |

5. Incremental capacity extraction

   Incremental capacity is calculated as:

   ```matlab
   processed_qIC_mat = diff(processed_Qd_mat, 1) / Vinterval;
   ```

   The resulting IC curves are reversed to follow the intended voltage direction and smoothed using a moving mean window of `5`.

## Reproduction

### Software requirements

The script was written for MATLAB and uses built-in functions including `load`, `save`, `smooth`, `smoothdata`, `interp1`, `unique`, `diff`, and standard plotting functions. Recommended environment:

| Software | Recommended version |
| --- | --- |
| MATLAB | R2021a or later |
| Operating system | Windows, Linux, or macOS with MATLAB support |

No external MATLAB toolbox is explicitly required by the script, provided that `smooth` and `smoothdata` are available in the installed MATLAB version.

### Run instructions

Place `CETL-data.mat` and `data_processing_code_V1.m` in the same folder, then run:

```matlab
run('data_processing_code_V1.m')
```

The script will:

1. load `CETL-data.mat`;
2. filter anomalous records;
3. generate quality-control and IC visualizations;
4. save `CETL_data_processed.mat` containing `processed_Qd_mat`, `processed_Vd_mat`, `processed_qIC_mat`, and `processed_vIC_mat`.
